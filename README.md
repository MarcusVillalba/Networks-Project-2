# Networks-Project-2
Marcus Villalba CS 1652 Project 2

  This project is a mock pregame lobby. In many online multiplayer videogames, teammates or competitors start their experience by joining a lobby. Consider, for instance, Fortnite. When players wish to queue into a game together, they join a lobby together where they can change their character models, modify their settings, etc. Then, when a player is ready to start the main gameplay, they "ready-up", and when all players of the lobby are ready, they are loaded into the game as a group. This project is a very small scale version of that. Players join the lobby of an arbitrary game. Their character model is just a single-colored dot, and in the lobby, they have the choice to change the color of their dot and ready up. The server keeps track of which players are ready, and if all players are ready, a countdown to the main gameplay begins. Were this a real product, the players would then be loaded into a game. The server handles many things. For instance, since each player is represented with a dot, it can be easy to lose track of who is who, so the server ensures that only one player can have a color at a time. Additionally, if a player closes the lobby window, the server will detect this and modify every remaining players' lobbies so that only the remaining players' dots are displayed. If a player disconnects during the countdown, the server will detect this, cancel the countdown, and remove this player's dot.
  This project uses UDP connection. The host runs the server out of their own computer, and anyone using the same wifi as the host can send and receive datagrams. The server registers the address of all users that send datagrams so it can respond. 
  To run this project yourself, you will need pygame. Install with "pip install pygame". I'm currently using pygame version 2.6.1.
